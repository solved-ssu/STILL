# 연결형 학습 공간 개선 TDD 증거

## 범위 결정

Codex와 Claude Sonnet이 저장소와 실행 화면을 각각 검토한 뒤 다음 범위에 합의했다.

- 15개 기본 소주제마다 실제로 읽을 수 있는 가이드 노트 1개를 제공한다.
- 예제 노트는 서로 다른 분야까지 내부 링크로 연결하고 코드 예제를 최소 1개 포함한다.
- 편집기에서 `[[`로 공개 노트를 검색해 표준 `/pages/<slug>` 링크를 삽입한다.
- 그래프는 초기 안정화 뒤에도 저에너지로 움직이되 약 30fps로 제한하고, 문서나 그래프가 보이지 않을 때 중단한다.
- 모바일에서도 홈·내 문서·북마크·설정·관리자 경로와 임시 저장을 유지한다.
- 그래프의 연결도, 선택 노드 정보, 연결이 없는 노트의 빈 상태를 설명한다.

| `b726f24` | 예제 코드·내부 링크의 실제 렌더링과 편집기 H1 구조 |

RED 실행에서는 없는 모듈·UI로 인한 예상 실패 외에 두 가지 실제 회귀를 발견했다.

- SQLite 조회 행을 그대로 클라이언트 컴포넌트에 넘겨 Next 16 직렬화 오류가 발생했다. 저장소에서 plain object로 명시 변환했다.
- 편집기에는 보이는 제목 입력이 있었지만 문서 구조상 H1이 없어 axe의 `page-has-heading-one` 규칙을 위반했다. 현재 제목을 반영하는 스크린리더용 H1과 제목 입력 레이블을 추가했다.

Playwright DB 이름이 PID만 사용해 Windows의 PID 재사용 시 과거 계정과 충돌한 문제도 실행 시각을 포함한 고유 경로로 수정했다.

## 구현 보증

- 시드 추가는 `INSERT OR IGNORE`를 사용하며 사용자가 수정한 기존 문서를 덮어쓰지 않는다. 기존 기본 세그먼트 트리 본문과 정확히 일치할 때만 새 가이드로 전진 마이그레이션한다.
- 모든 소주제는 최소 1개 공개 노트를 가지며, 15개 노트가 30개 방향 링크로 연결된다.
- 링크 피커는 대소문자를 무시하는 부분 일치, 제목 정렬, 최대 8개 결과를 제공하고 현재 문서는 제외한다.
- 그래프는 유한 좌표와 계산 예산을 유지하고, 참조선의 힘을 계층선보다 약하게 적용해 분야 구조를 보존한다.
- `prefers-reduced-motion`, `visibilitychange`, `IntersectionObserver`, 정지·재생 버튼을 모두 존중한다.
- 전체 그래프에서는 노트 제목을 숨겨 겹침을 줄이고, hover·키보드 포커스·검색 선택·확대·분야 필터 시 필요한 제목과 상세 정보를 보여 준다.
- 홈은 공개 노트·연결된 노트·활성 분야 수와 연결도가 높은 길잡이 노트를 먼저 보여 준다.

## 잔여 한계

- 홈 그래프는 성능을 위해 최근 공개 노트 60개까지만 표시한다. 현황의 전체 노트 수와 그래프의 표시 수는 분리해 안내한다.
- 공개 문서 전체 제목을 편집기 진입 시 전달하므로 문서가 수천 개 이상으로 늘면 서버 검색 API나 지연 로딩으로 전환해야 한다.
- 노드 위치는 개인화해 저장하지 않는다. 현재는 매 진입 시 결정적 초기 배치와 힘 시뮬레이션으로 구성한다.
- 전용 백링크 패널과 랜딩 화면의 실데이터 통계는 이번 범위에서 제외했다.
